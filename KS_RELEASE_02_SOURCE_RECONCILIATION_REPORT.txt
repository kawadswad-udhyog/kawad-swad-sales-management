2. STAGE 3 — FRONTEND ACCEPTANCE HARNESS & REAL UI RUNTIME CRASH REMEDIATION
--------------------------------------------------------------------------------
Status: PASSED (2 Real Production React Crashes Fixed + Audit Harness Repaired)

Exact BEFORE Failure Evidence (captured against live http://localhost:3000):
  1. Real Production Crash #1 — src/views/StockView.tsx:186
     - Error: `TypeError: loadingPasses.filter is not a function`
     - Cause: `loadLoadingPasses()` called `setLoadingPasses(res || [])` without an
       `Array.isArray(res)` guard (unlike `loadBulkBatches` on line 418), crashing
       StockView whenever an API endpoint returned a non-array envelope object.
     - Fix: Added `Array.isArray(res)` / `Array.isArray(res?.items)` normalization in
       `loadLoadingPasses` (lines 182-198) and `Array.isArray(res?.register)` guard in
       `loadRegister` (line 482).

  2. Real Production Crash #2 — src/views/ReportsView.tsx:269 & 286
     - Error: `TypeError: Cannot read properties of undefined (reading 'length')`
     - Cause: `officialReport.rows.length` and `Object.keys(officialReport.rows[0])`
       assumed `officialReport.rows` was always an array, crashing React ErrorBoundary
       when `/api/v2/reports/*` returned a partial/error payload without `rows`.
     - Fix: Guarded `officialRows = Array.isArray(officialReport.rows) ? officialReport.rows : []`
       and `officialCols` prior to `.length` and `.map()` rendering (lines 240-306).

  3. Audit Harness Bugs — scripts/run_frontend_acceptance_audit.cjs
     - Bug A (Playwright LIFO Route Shadowing): Catch-all `context.route('**/api/**', ...)`
       was registered LAST, causing Playwright (which evaluates routes in LIFO order)
       to shadow `/api/auth/me`, `/api/workspace`, `/api/dashboard`, and `/api/health`,
       corrupting `currentUser` and breaking OWNER/PA/MANAGER/FACTORY/ACCOUNTANT/EMPLOYEE
       and security checks. Fixed by registering the catch-all FIRST and adding realistic
       mocks for `/api/stock/loading-passes**`, `/api/stock/finished-goods-register**`,
       and `/api/v2/reports/**`.
     - Bug B (Syntax/Logic Typo): Line 400 had `if (dashNavBtn => mgrDashBtn)` (arrow
       function always truthy). Fixed to `if (mgrDashBtn)`.
     - Bug C (Pre-v2 Workspace/Nav Labels): Updated Factory/Accountant/Salesman header
       checks and Accounting nav selector to align with canonical v2 `src/utils/workspaces.ts`
       (`Production Floor`, `Accounts & Finance`, `Field Sales Mobile`, `Money Records`),
       which is contract-enforced by `scripts/test_phase1_6_frontend_contracts.ts` Test 17.
     - Bug D (Exit Code Enforcement): Added strict `process.exitCode = 1` whenever ANY
       workflow, security check, responsive check, or console error fails. Zero security
       assertions were weakened or removed.
