       * Non-array JSON objects for both outer wire envelope and inner `canonical_envelope`,
         plus object check on `envelope.payload` (HTTP 400).

       * Strict ISO-8601 UTC/offset regex (`KS_BRIDGE_ISO8601_TZ_RE`) and +/-300s clock skew (HTTP 401).

2. Mandatory Actor Attribution & Zero Anonymous Privileged Writes:
   - `WebAppBridge.js:230-241` rejects any request missing `actor_user_id` or `actor_role`
     with `MISSING_ACTOR_IDENTITY` (HTTP 401) before lock acquisition or write execution.
   - Removed `'FASTAPI_GATEWAY'` anonymous fallback on `AuditLog` entries.
   - Backend enforces JWT authentication + 12-role default-deny RBAC (`backend/app/permissions.py`),
     Owner-only authority boundaries (`POL-012`), confidential payroll redaction (`POL-013`),
     and read-only `AUDITOR` lock (`POL-014`).

   - `WebAppBridge.js::ksValidateBridgeTargetTab_` blocks:
       * Immutable governance tabs (`AuditLog`, `IdAllocations`, `ExceptionRegister`) -> 403.
       * Legacy scratch tab prefixes (`KS_P1_*`, `KS_P2_*`, `KS_P3_*`, `DBV5_*`, `DB_*`) -> 403.
       * Unauthorized `AuthUsers` writes (permits only `REVOKE_USER_SESSIONS`,
         `CHANGE_PASSWORD`, `RESET_PASSWORD`) -> 403.
       * Any tab outside the explicit canonical ERP allowlist -> 403.

4. Uninterrupted ScriptLock Ownership, Idempotency & Monotonic Non-Recycled IDs:
   - `IdAllocator.js::ksAllocateIdLocked_` refuses execution unless caller holds `ScriptLock`
     (`LOCK_OWNERSHIP_VIOLATION`), never acquires/releases locks internally, never recycles IDs,
     returns `EXISTING_IDEMPOTENT` on same `(tab_name, nonce)`, verifies writes via
     `ksAppendAndVerifyRow_`, and matches `/^ALLOC-(\d{1,9})$/` (immune to legacy epoch rows).
   - `WebAppBridge.js` checks `existing.tab_name !== targetTab` on replay and rejects cross-table
     nonce collisions (`NONCE_TARGET_TAB_CONFLICT`, HTTP 409).
   - `WebAppBridge.js::ksRecordIdAllocation_` allocates monotonic `ALLOC-0000001` IDs with
     flush and read-back verification.

5. Mandatory Strict Audit Logging & Post-Write Quarantine:
   - `AuditAndExceptions.js::ksLogAuditStrictLocked_` requires caller-held `ScriptLock`,
     allocates `AUD-*` via `ksAllocateIdLocked_` without releasing lock, never swallows errors,

   - `WebAppBridge.js` verifies an audit logger is loaded before mutating any tab (HTTP 503),
     executes `ksLogAuditStrictLocked_` while holding `ScriptLock`, and quarantines any
     post-write error (allocation, audit, read-back, flush) as `RECOVERY_REQUIRED` (HTTP 409).
