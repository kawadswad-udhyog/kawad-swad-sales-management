1. Download and extract this ZIP.
2. Open the existing GitHub repository: kawad-swad-sales-management.
3. Upload the package contents to the repository root, preserving folder structure.
4. Replace matching files and commit to main.
5. Let the existing Render service deploy from GitHub.
6. Do not delete or change existing Render environment variables or Secret Files.
